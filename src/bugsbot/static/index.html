Start a remote worker

A remote worker is a Claude Code Remote Control session running on the bugsbot host. You don't chat with it here. Open it in the Claude app (claude.ai/code, or the Claude desktop or mobile app) and talk to it there, as you would any Claude Code session.

  • It appears in the Claude account that's logged in to Claude Code on the bugsbot host, and only that account can open it. That account needs a Claude subscription, and usage counts against it. bugsbot tracks the worker's duration but not its cost.
  • It works in a fresh checkout of the repository you pick, or in an empty scratch folder.
  • Like bugsbot's other agents, it can push branches, open PRs and comment (all signed) but can never merge.
